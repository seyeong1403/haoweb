Design steps

제작 전에
정리하는 다섯 가지.

기능 목록을 늘리기 전에, 무엇을 먼저 만들지와 사용자가 어떻게 움직일지를 정합니다.

  1. 주요 기능

    핵심 기능을 우선순위로 정합니다. 전부가 아니라 먼저 필요한 것부터.

  2. 서비스 흐름

    가입부터 핵심 행동까지의 흐름을 그립니다.

  3. 화면 목록

    필요한 화면을 목록으로 확정합니다.

  4. 사용자 동선

    화면 사이의 이동과 반복 사용 경로를 설계합니다.

  5. 운영 기능

    관리자에서 무엇을 관리할지 정합니다.

Scope

기본으로 만드는 것과,
별도로 진행하는 것.

  • 관리자 연동
  • 홈페이지 콘텐츠 연동
  • PWA 또는 하이브리드 패키징 검토
